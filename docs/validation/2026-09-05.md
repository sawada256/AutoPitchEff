M4 MacBook Air上で検証。Universalバイナリのarm64とx86_64（Rosetta）を実行しました。物理Intel Mac、Cubase 13実セッション、SM58とUMC204HDによるライブ入力・往復遅延の測定は未実施です。

- 実VST3を独自JUCEホストにロード: arm64 / x86_64とも成功。44.1 / 48 / 96 kHz、ブロック1 / 32 / 64 / 127 / 256 / 1024 samplesで有限かつ非無音の出力を確認。状態保存・復元、レイテンシー申告、900×650のエディター生成も確認。
- DSPテスト: 両アーキテクチャ成功。196–937 Hzの合成音の検出・補正、伴奏混入、無音、バイパス、異常値、リセット再現性、処理中の通常C++ヒープ確保の監視を含みます。
- AddressSanitizer / UndefinedBehaviorSanitizer: DSPテスト成功。
- 合成音440→659 Hzの検出切り替え: 約9.98 ms。全ての歌声の取得時間ではありません。

## 精度

RPA50は参照F0から±50 cents未満に入った参照有声フレームの割合です。未検出も失敗に数え、時間ずらしによる整列補正はしていません。これは入力のピッチ検出精度であり、補正済み音声の精度とは別です。

| 入力 | RPA50 |
| --- | ---: |
| 合成歌声 | 99.46% |
| 合成歌声 + 人工伴奏、声が10 dB大きい | 99.38% |
| 合成歌声 + 人工伴奏、声が5 dB大きい | 98.90% |
| 合成歌声 + 人工伴奏、同音量 | 90.07% |
| vocadito実歌声11曲 | 93.49% |
| vocadito実歌声 + 人工伴奏、声が10 dB大きい | 86.77% |

合成歌声は8秒の倍音音源、音符移動・ビブラート・無音区間を含みます。伴奏はギター／ベース相当の周期音と雑音打撃音で、実バンド収録ではありません。単独合成歌声の安定区間に対する独立した出力ピッチ測定は、目標音からの絶対誤差中央値2.75 cents、95パーセンタイル4.13 centsでした。安定区間の出力測定は音符変化や無音を除くため、全時間の品質を表しません。同音量の伴奏では検出誤差95パーセンタイルが約1203 centsとなり、オクターブ誤りが残っています。

実歌声には[vocadito（Bittnerら、2021、CC BY 4.0）](https://zenodo.org/records/5578807)を使用しました。公開メタデータの平均MIDI音高60以上という条件で選んだ11曲（2, 6, 7, 9, 15, 17, 25, 37, 38, 39, 40）の、参照F0が180–1200 Hzに入るフレームを採点しています。性別の選別ではありません。範囲外の低音や他の29曲を含む全集合への精度を示しません。

この11曲の結果を検出帯域の重み調整にも用いたため、独立した未使用テスト集合ではなく**開発用ベンチマーク**です。無声区間での誤検出も残り、例として40番の単独歌声で約25.9%です。息・子音・残響の境界で参照注釈と異なる追跡が生じます。曲別の結果は[vocadito.json](vocadito.json)に収録しています。

## 遅延と処理時間

申告する固定ガード8 samplesに加え、補正時は読み出す過去音声の位置が可変です。単独合成歌声における読み出し位置の年齢は中央値1.16 ms、99パーセンタイル3.18 msでした。クロスフェード中は古い側の読み出し位置を使う指標です。音響的な群遅延や、機器を含む往復遅延の実測ではなく、全音域で5 ms以内を保証する指標でもありません。

最新オフライン計測のDSP wall-time RTFは約0.066–0.143でしたが、64 samples単位の最大wall-timeに12–172 msの外れ値がありました。通常優先度のプロセスのスケジューリング停止を含むため、リアルタイムの締切達成を証明しません。実際のCubase音声コールバックでのドロップアウト検証が必要です。平均速度だけでライブ運用が安全とは判断していません。

生の数値は[synthetic.json](synthetic.json)、互換性検査（pluginval）は当時のログを公開版から省略しています。ホスト検査は[ARMホスト](host-arm.log)、[Intelホスト](host-intel.log)を参照してください。
